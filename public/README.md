# Публичные ассеты

В этой папке лежат публичные файлы плагина.

## Логотип

- `logo.svg` — квадратный логотип плагина.

Растровая версия логотипа для README и внешних площадок находится в `docs/assets`, чтобы не попадать в production build плагина.

## Подсказка для ИИ-агентов

Если вы готовите плагин к публикации, убедитесь, что `logo.svg` остаётся квадратным и корректно отображается на светлом фоне.
