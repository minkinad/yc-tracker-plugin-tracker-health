# Интерфейс плагина Tracker

## Перед кодом

1. Прочитай [SLOT.md](./SLOT.md) и проверь выбранные слоты в `manifest.json`: место встраивания определяет размер и поведение интерфейса.
2. Выбери компоненты по таблице ниже. Проверь установленные версии в `node_modules/<package>/package.json`, затем прочитай документацию только выбранных компонентов.
3. Передай тему хоста в `ThemeProvider`. Для оформления Орбиты прочитай [рецепт](./design/ORBITA.md) и сверь его с требованиями задачи. Собери интерфейс с состояниями загрузки, пустых данных и ошибки.
4. Выполни проверку результата в конце этого файла.

## Сценарий → компонент

Компоненты предметной области бери из `@weavix/tracker-components`, базовые контролы и компоновку — из `@gravity-ui/uikit`, пиктограммы — из `@gravity-ui/icons`. Проверь экспорт и props по установленной версии перед импортом.

| Сценарий                                      | Компонент                                                            | Где читать и какие данные нужны                                                                                                                                                      |
| --------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Выбор очереди                                 | `QueueSelect` из Tracker Components                                  | `components/QueueSelect/README.md`; список очередей или callback поиска                                                                                                              |
| Выбор проекта, портфеля, цели                 | `MetaEntitiesSelect` из Tracker Components                           | `components/MetaEntitiesSelect/README.md`; callback получения сущностей                                                                                                              |
| Выбор полей                                   | `PluginFieldsSelect` из Tracker Components                           | `components/PluginFieldsSelect/README.md`; список полей и выбранные значения                                                                                                         |
| Тип, приоритет, статус задачи                 | `IssueTypeIcon`, `PriorityIcon`, `StatusIcon` из Tracker Components  | `components/Icon/<Component>/README.md`; передай значение из API                                                                                                                     |
| Иконка проекта, портфеля, цели                | `MetaEntityIcon` или соответствующий компонент из Tracker Components | `components/Icon/<Component>/README.md`; тип и идентификатор сущности                                                                                                                |
| Раскрываемая секция                           | `TrackerDisclosure` из Tracker Components                            | `components/TrackerDisclosure/README.md`                                                                                                                                             |
| Форма и действия                              | `TextInput`, `TextArea`, `Select`, `Checkbox`, `Button` из Gravity   | README и типы выбранного компонента; label, validation, loading                                                                                                                      |
| Таблица во вкладке                            | `Table` из Gravity                                                   | README `Table`; колонки, сортировка и действия по сценарию. Для сложной таблицы сначала сравни с `@gravity-ui/table` по каталогу пакетов                                             |
| Компоновка и текст                            | `Flex`, `Box`, `Text` из Gravity                                     | Документация layout и типы компонентов                                                                                                                                               |
| Уведомление, подтверждение, переход в Tracker | `useToaster`, `useConfirm`, `uiApi.navigate` из SDK                  | [React API](./node_modules/@weavix/tracker-plugin-sdk-react/API_REFERENCE.md), [core API](./node_modules/@weavix/tracker-plugin-sdk/API_REFERENCE.md); permissions по выбранному API |

В таблице пути `components/...` относительны к каталогу документации библиотеки. В `@weavix/tracker-components@0.1.5` это `node_modules/@weavix/tracker-components/build/esm/` (также есть `build/cjs/`). Ссылки корневого README на `src/` в этой версии не работают в npm-пакете; открывай соответствующий файл в `build/esm/`. При обновлении пакета проверяй его фактическую структуру.

Select-компоненты Tracker принимают данные и callbacks: загрузку через `trackerApi` реализует плагин. По README компонента найди пример интеграции, сверь endpoint с установленными api-types, а permissions — с `manifest.schema.json` и SDK. Само отображение иконки или текста не требует добавлять доступ к API.

## Источники Gravity

Начни с `node_modules/@gravity-ui/<package>/build/docs/INDEX.md` или `dist/docs/INDEX.md`; если их нет — с README и `.d.ts` установленного пакета. Это источник API конкретной версии.

Если локальной документации недостаточно:

- [Каталог пакетов](https://gravity-ui.com/llms.txt) помогает выбрать библиотеку для таблиц, графиков, дат и навигации.
- Документация major-версии: `https://gravity-ui.com/llms/<package>/<major>/llms.txt`. Версию возьми из установленного пакета; онлайн-документация может описывать более новый minor, поэтому props сверяй с локальными типами.
- [Репозиторий uikit](https://github.com/gravity-ui/uikit) содержит README и примеры компонентов; выбирай tag установленной версии.
- [Gravity UI skill](https://github.com/gravity-ui/skills) содержит дополнительные рецепты. Если он установлен, используй его для Gravity-части задачи вместе с правилами этого проекта: Tracker Components и UI API хоста остаются предпочтительными для сценариев из таблицы. Обязательные шаги этого файла доступны без установки skill.

Проверяй имена иконок по экспортам `@gravity-ui/icons`. У Gravity `Button` использует `view`, `Icon` — `data`; значения `Text.variant` проверяй по типам. Завершай проверкой типов, чтобы обнаружить несовпадение API и версии документации.

## Тема и Орбита

Сохраняй `TrackerPluginProvider` из стартового проекта. Получай `theme`, `language` и `isOrbita` через `useTrackerPluginContext()`; передавай тему в существующий Gravity `ThemeProvider`. Переключение темы должно работать без перезагрузки iframe.

Используй семантические токены Gravity `--g-color-*`, `--g-spacing-*`, типографику `Text` и CSS API компонентов. Сначала используй готовые стили из `src/styles.scss` и `src/themes/`, затем добавляй стили плагина. Для сжатия текста во flex-контейнере проверь `min-width: 0` и переносы.

`isOrbita` — отдельный флаг оформления хоста, а не светлая/тёмная тема; до инициализации он может быть `undefined`. Подключение шрифта и переключение стилей описаны в [рецепте Орбиты](./design/ORBITA.md). Шрифт и SCSS уже включены в шаблон; рецепт указывает источник и границы применимости примера.

## Эталоны компоновки

| Место              | Состав интерфейса                                             | Состояния для проверки                                                                   |
| ------------------ | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Строка задачи      | Ключ и название; статус/приоритет по задаче; имя исполнителя  | Длинное название, отсутствующий исполнитель                                              |
| Модальное действие | Короткий заголовок, поля с labels, основное действие и отмена | Валидация, выполнение, ошибка с сохранением ввода; повторное нажатие во время сохранения |
| Вкладка            | Заголовок, фильтры и таблица/список результатов               | Загрузка, пустая выборка, ошибка с повтором, узкая вкладка в drawer                      |
| Блок задачи        | Компактная сводка или раскрываемая секция                     | Нет данных, длинные значения, малая ширина; высотой управляет resize SDK                 |

Открывай ссылки и показывай подтверждения через SDK из таблицы. Для отображаемых имён и других локализованных полей используй `useLocalizedString()`.

## Проверка результата

1. Запусти скрипты lint и build из `package.json`; исправь ошибки типов, импортов и стилей.
2. Через debug-команду CLI открой плагин в целевом слоте. Проверь светлую/тёмную тему, узкий контейнер, длинные строки, загрузку, пустое состояние и ошибку. При поддержке Орбиты проверь оба значения флага.
3. Проверь консоль и сетевые ошибки iframe, включая загрузку шрифтов и CSP.
4. В результате работы укажи выполненные проверки и непроверенные состояния. Успешная сборка подтверждает компиляцию; визуальную проверку подтверждает просмотр интерфейса в хосте.
