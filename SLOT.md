# Слоты шаблона `tracker/issue.block`

Слоты при создании: `issue.block`, `drawer.issue.block`.

Начальный `contextLevel`: `basic`.

Актуальные слоты и уровни контекста проверяй в `manifest.json`.

## Расположение и сценарий

Раскрываемая секция под описанием и связями задачи загружается вместе со страницей. Подходит для постоянно полезной сводки: статусы проверок, связанные PR, сведения из внешней системы.

`drawer.issue.block` — такая же секция в боковой панели задачи с ограниченной шириной. Шаблон включает оба варианта; интерфейс должен помещаться в каждом.

## Контекст и результат

В basic `entityId` идентифицирует задачу. Полный контекст — `Issue`. Для full в обоих вариантах обнови обе записи манифеста:

```tsx
const { slotContext } = useTrackerPluginContext<'issue.block' | 'drawer.issue.block'>('full');
const issueKey = slotContext?.key;
```

Показ блока сам по себе не сохраняет данные задачи. Для изменений используй `trackerApi`; специальный результат закрытия для блока не определён.

## Интерфейс

Показывай компактные данные без предварительного ввода. Высота должна соответствовать содержимому: большой блок вытесняет остальную страницу. Для объёмных таблиц и фильтров подходит вкладка.

## Работа с контекстом и SDK

Используй `useTrackerPluginContext()` из `@weavix/tracker-plugin-sdk-react`: тема, язык, текущий слот и контекст уже доступны через провайдер.

- В режиме `basic` доступны `{ entityId, entityMeta? }`; контекст может отсутствовать. Значение `entityId` зависит от слота, а дополнительные поля `entityMeta` используй только при подтверждённом контракте хоста.
- Для полного контекста установи `contextLevel: "full"` у нужных записей в `manifest.json` и вызови `useTrackerPluginContext('full')`. При базовом уровне в манифесте этот вызов завершится ошибкой. Обычный вызов хука возвращает basic даже при полном уровне в манифесте.
- Обрабатывай загрузку и отсутствие контекста; пересчитывай данные при изменении контекста. Нужные дополнительные данные получай через `trackerApi`, проверяя пути и permissions по SDK.
- `TrackerPluginProvider` по умолчанию управляет готовностью и автоматическим resize. Делай адаптивный интерфейс; размеры контейнера определяет хост.

Перед работой с API прочитай [инструкции SDK](./node_modules/@weavix/tracker-plugin-sdk/AGENTS.md); сигнатуры хуков и контекста смотри в [React API Reference](./node_modules/@weavix/tracker-plugin-sdk-react/API_REFERENCE.md).
