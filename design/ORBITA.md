# Тема хоста и Орбита

## Применимость

Это готовый вариант типографики, а не утверждённая спецификация Орбиты. Если в задаче дан дизайн-образец или актуальная спецификация, используй их; сам флаг `isOrbita` не подтверждает выбор шрифта. Подключай этот вариант, когда он соответствует требованиям задачи.

## Типографика примера

| Текст                                               | Шрифт                          |
| --------------------------------------------------- | ------------------------------ |
| Основной текст, `header-*`, `subheader-*`           | `YS Text`                      |
| Крупные заголовки `display-*` при включённой Орбите | `YS Text Wide 110`, weight 500 |

Используй `Text` с подходящим `variant`. Широкий шрифт предназначен для крупных заголовков, а не всех подписей и контролов. Размеры, интервалы и цвета бери из токенов текущей темы.

Шаблон содержит `src/themes/orbita.scss` и `public/fonts/ys-text-display-wide-110.woff2`. Базовый `YS Text` объявлен в `src/themes/ys-text.scss`. Стили Орбиты автоматически не подключаются.

## Подключение

В компоненте, который уже оборачивает приложение в Gravity `ThemeProvider`, добавь импорт стилей и передай класс Орбиты через `rootClassName`. Ниже обёртка, которую можно использовать вместо существующего `ThemeProvider`; она должна находиться внутри `TrackerPluginProvider` из `src/main.tsx`.

```tsx
import type { PropsWithChildren } from 'react';
import { ThemeProvider } from '@gravity-ui/uikit';
import { useTrackerPluginContext } from '@weavix/tracker-plugin-sdk-react';

import './themes/orbita.scss';

export function PluginTheme({ children }: PropsWithChildren) {
  const { theme, isOrbita } = useTrackerPluginContext();

  return (
    <ThemeProvider theme={theme} rootClassName={isOrbita === true ? 'plugin-orbita' : undefined}>
      {children}
    </ThemeProvider>
  );
}
```

Путь импорта рассчитан на компонент в `src/`; адаптируй относительный путь при другом расположении. Сохраняй существующие props и классы провайдера, если они уже используются.

`theme` управляет светлым/тёмным оформлением, `isOrbita` — дополнительным классом. Правила типографики ограничены `.g-root.plugin-orbita`, поэтому при `false` или `undefined` работает базовая тема шаблона. При смене флага класс снимается и исходная типографика восстанавливается.

Стили подключаются один раз, а применение управляется классом: уже загруженный CSS не нужно выгружать при обратном переключении. Используй локальные `src/themes/` текущего шаблона.

## Проверка

- При `isOrbita === true` крупный `Text variant="display-1"` использует `YS Text Wide 110`, а основной текст и `header-*`/`subheader-*` — `YS Text`.
- В Network шрифт загружается без 404 и CSP-ошибок; проверь фактически используемый шрифт в инструментах браузера, а не только значение CSS-переменной.
- При переключении `true → false → true` оформление меняется без перезагрузки iframe.
- Светлая/тёмная тема переключается независимо от Орбиты; контраст и размеры контролов сохраняются.
- Сборка включает WOFF2-ассет; проверь его загрузку также из production-сборки с путём размещения плагина.
