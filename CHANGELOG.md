# История изменений

Значимые изменения Tracker Health фиксируются в этом файле. Проект следует
[Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.1.1] — 2026-09-12

### Изменено

- Уточнены локализованные названия, категории и описание для будущей публикации в каталоге Яндекс Трекера.
- Минимальная версия Node.js повышена до `22.16.0`; lint и TypeScript typecheck разделены на независимые проверки.
- Дополнены README и описание для Marketplace, включая сведения о статусе независимого open-source проекта.

### Правовая информация

- Восстановлена MIT License для оригинального кода Tracker Health.
- Добавлен `NOTICE.md` с информацией о сторонних SDK, библиотеках, сгенерированных материалах и шрифтах.
- Уточнены границы применения MIT License и принадлежность товарных знаков.

Функциональность, Health Engine, правила, веса и UI-поведение не изменялись.

## [0.1.0] — 2026-09-12

### Добавлено

- Интеграция со слотами `issue.block` и `drawer.issue.block` через полный контекст задачи.
- Чистый Health Engine с оценкой от 0 до 100 и уровнями `healthy`, `warning` и `critical`.
- Шесть взвешенных проверок: исполнитель, приоритет, описание, тип задачи, оценка и критерии приёмки.
- Распознавание английских и русских заголовков критериев приёмки без ложных совпадений внутри предложений.
- Infrastructure Adapter для безопасного преобразования nullable-данных Yandex Tracker в доменную модель.
- Компактный интерфейс на Gravity UI с темой хоста, раскрываемым списком правил и явными текстовыми статусами.
- Состояния загрузки и ошибки, повторный анализ и React Error Boundary.
- Поведенческие тесты доменного, инфраструктурного, прикладного и UI-слоёв.
- CI для lint, typecheck, тестов и production build на push и Pull Request в `main`.
- Русскоязычная документация, скриншоты, логотип и обложка для будущей публикации.

### Безопасность и приватность

- Анализ выполняется локально внутри плагина без внешнего backend, отдельной базы данных и постоянного хранилища.
- Данные задачи не передаются внешним сервисам; AI и ML в v0.1 не используются.
